# Internationalization (i18n) Guide

NgxWebTour comes with built-in support for multiple languages!

## 🌍 Supported Languages (Out of the Box)

- **English** (en) - Default
- **Persian/Farsi** (fa) 
- **Arabic** (ar)
- **Spanish** (es)
- **French** (fr)
- **German** (de)
- **Turkish** (tr)
- **Russian** (ru)
- **Chinese** (zh)
- **Japanese** (ja)
- **Korean** (ko)
- **Portuguese** (pt)
- **Italian** (it)

## 🚀 Quick Start

### Auto-Detection (Recommended)

The library automatically detects the browser language:

```typescript
import { TourService } from '@abbasmgz/ngx-web-tour';

constructor(private tourService: TourService) {}

// Just start the tour - it will use browser language automatically
this.tourService.start('my-tour');
```

### Manual Language Selection

```typescript
import { TourService } from '@abbasmgz/ngx-web-tour';

this.tourService.start('my-tour', {
  language: 'fa' // Persian
});
```

## 🔧 Using TourI18nService

### Change Language Globally

```typescript
import { TourI18nService } from '@abbasmgz/ngx-web-tour';

constructor(private i18nService: TourI18nService) {}

// Change language
this.i18nService.setLanguage('fa'); // Persian
this.i18nService.setLanguage('ar'); // Arabic
this.i18nService.setLanguage('es'); // Spanish
```

### Get Current Language

```typescript
const currentLang = this.i18nService.getCurrentLanguage();
console.log('Current language:', currentLang);
```

### Listen to Language Changes

```typescript
this.i18nService.language$.subscribe(lang => {
  console.log('Language changed to:', lang);
});
```

## ✨ Custom Translations

### Add Translations for a New Language

```typescript
import { TourI18nService } from '@abbasmgz/ngx-web-tour';

this.i18nService.addTranslations('nl', {
  nextBtn: 'Volgende',
  prevBtn: 'Vorige',
  doneBtn: 'Klaar',
  skipBtn: 'Overslaan',
  closeBtn: 'Sluiten',
  stepIndicator: '{current} van {total}',
});

// Now use Dutch
this.tourService.start('my-tour', { language: 'nl' });
```

### Override Existing Translations

```typescript
// Customize English translations
this.i18nService.addTranslations('en', {
  nextBtn: 'Next Step →',
  prevBtn: '← Go Back',
  doneBtn: '✓ Finish',
});
```

### Add Multiple Languages at Once

```typescript
this.i18nService.addMultipleTranslations({
  nl: {
    nextBtn: 'Volgende',
    prevBtn: 'Vorige',
    doneBtn: 'Klaar',
  },
  sv: {
    nextBtn: 'Nästa',
    prevBtn: 'Föregående',
    doneBtn: 'Klar',
  },
});
```

## 🎯 Translation Keys

Available translation keys:

| Key | Description | Example (EN) |
|-----|-------------|--------------|
| `nextBtn` | Next button text | "Next" |
| `prevBtn` | Previous button text | "Previous" |
| `doneBtn` | Done button text | "Done" |
| `skipBtn` | Skip button text | "Skip" |
| `closeBtn` | Close button text | "Close" |
| `stepIndicator` | Step counter format | "{current} / {total}" |

## 🔀 RTL (Right-to-Left) Support

Automatic RTL detection for languages like Arabic, Persian, and Hebrew:

```typescript
const isRTL = this.i18nService.isRTL();

if (isRTL) {
  // Apply RTL styles
  document.dir = 'rtl';
}
```

## 📚 Complete Examples

### Example 1: Multi-Language Tour

```typescript
import { Component, OnInit } from '@angular/core';
import { TourService, TourI18nService } from '@abbasmgz/ngx-web-tour';

@Component({
  selector: 'app-multilingual',
  template: `
    <div>
      <select (change)="changeLanguage($event)">
        <option value="en">English</option>
        <option value="fa">فارسی</option>
        <option value="ar">العربية</option>
        <option value="es">Español</option>
        <option value="fr">Français</option>
      </select>

      <button (click)="startTour()">Start Tour</button>

      <div tour="demo" tourText="Welcome message" [tourPriority]="1">
        Content
      </div>
    </div>
  `,
})
export class MultilingualComponent implements OnInit {
  constructor(
    private tourService: TourService,
    private i18nService: TourI18nService
  ) {}

  ngOnInit() {
    // Set default language
    this.i18nService.setLanguage('en');
  }

  changeLanguage(event: any) {
    const lang = event.target.value;
    this.i18nService.setLanguage(lang);
  }

  startTour() {
    this.tourService.start('demo');
  }
}
```

### Example 2: Custom Translations

```typescript
import { Component, OnInit } from '@angular/core';
import { TourI18nService, TourService } from '@abbasmgz/ngx-web-tour';

@Component({...})
export class CustomTranslationsComponent implements OnInit {
  constructor(
    private tourService: TourService,
    private i18nService: TourI18nService
  ) {}

  ngOnInit() {
    // Add custom brand-specific translations
    this.i18nService.addTranslations('en', {
      nextBtn: 'Continue →',
      prevBtn: '← Back',
      doneBtn: "Let's Go! 🚀",
      stepIndicator: 'Step {current} of {total}',
    });

    this.i18nService.addTranslations('fa', {
      nextBtn: 'ادامه ←',
      prevBtn: '→ بازگشت',
      doneBtn: 'بزن بریم! 🚀',
      stepIndicator: 'مرحله {current} از {total}',
    });
  }

  startTour() {
    this.tourService.start('my-tour', {
      language: 'fa',
      useI18n: true,
    });
  }
}
```

### Example 3: Disable i18n (Use Static Text)

```typescript
// If you want to use static text instead of i18n
this.tourService.start('my-tour', {
  useI18n: false,
  nextBtnText: 'Next',
  prevBtnText: 'Previous',
  doneBtnText: 'Done',
});
```

## 🛠️ Advanced Usage

### Check Available Languages

```typescript
const languages = this.i18nService.getAvailableLanguages();
console.log('Available languages:', languages);
// Output: ['en', 'fa', 'ar', 'es', 'fr', 'de', ...]
```

### Check if Language is Supported

```typescript
const isSupported = this.i18nService.isLanguageSupported('fr');
console.log('French supported:', isSupported); // true
```

### Get Translations Programmatically

```typescript
// Get a specific translation
const nextText = this.i18nService.translate('nextBtn');

// Get translation with parameters
const stepText = this.i18nService.translateWithParams('stepIndicator', {
  current: 2,
  total: 5,
});
console.log(stepText); // "2 / 5" (in English)
```

### Reset to Default Translations

```typescript
this.i18nService.resetTranslations();
```

## 🌐 Integration with Angular i18n

You can also integrate with Angular's built-in i18n:

```typescript
import { LOCALE_ID, Inject } from '@angular/core';

constructor(
  @Inject(LOCALE_ID) private locale: string,
  private i18nService: TourI18nService
) {
  // Use Angular's locale
  const lang = locale.split('-')[0]; // 'en-US' -> 'en'
  this.i18nService.setLanguage(lang);
}
```

## 🎨 Per-Step Translations

You can also override translations per step:

```html
<div
  tour="my-tour"
  tourText="Step content"
  tourNextBtnText="Continue"
  tourPrevBtnText="Go Back"
  tourDoneBtnText="Finish"
  [tourPriority]="1"
>
  Content
</div>
```

Priority order:
1. Step-level translations (tourNextBtnText, etc.)
2. Config-level translations (in `start()` config)
3. i18n service translations (based on language)
4. Default English translations
